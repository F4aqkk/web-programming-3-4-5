# Веб-программирование — практические задания 3, 4, 5

| Пара | Тема | Файлы |
|------|------|-------|
| 3 | Условные операторы, формирование HTML — «Результат студента» | `pair3/student_result.php` |
| 4 | Веб-формы, передача данных из HTML в PHP | `pair4/form.html`, `pair4/process.php` |
| 5 | Cookie, HTTP-заголовки и сессии | `pair5/login.php`, `pair5/welcome.php`, `pair5/logout.php` |

## Запуск

Нужен PHP 7.4+. Из корня репозитория:

```bash
php -S localhost:8000
```

Затем открыть в браузере:

- http://localhost:8000/pair3/student_result.php
- http://localhost:8000/pair4/form.html
- http://localhost:8000/pair5/login.php
